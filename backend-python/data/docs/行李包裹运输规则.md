# 行李包裹运输规则

## 免费携带品

旅客免费携带品的重量和体积，成人不得超过 20 千克，儿童（含免票儿童）不得超过 10 千克。

每件物品外部尺寸长、宽、高之和不得超过 160 厘米，杆状物品不得超过 200 厘米，且重量不超过 20 千克。乘坐动车组列车时，每件物品外部尺寸长、宽、高之和不得超过 130 厘米。

## 超重超限处理

超过免费携带品重量或体积的，须办理托运手续。在发站发现的，按超重部分核收运费；在途中或到站发现的，加倍核收运费。

## 不得带入车厢的物品

下列物品不得带入车厢：国家禁止或限制运输的物品；法律、法规、规章中规定的危险品；动物及妨碍公共卫生的物品（导盲犬除外）；能够损坏或污染车辆的物品；规格或重量超过规定的物品。

## 包裹运输

包裹每件最大重量为 50 千克，最小体积不得小于 0.01 立方米。包裹的运到期限按里程计算：运价里程不足 200 公里的，为 2 日；200 公里以上的，每增加 200 公里或其不足 200 公里的尾数增加 1 日。

## 保价运输

办理包裹保价运输的，须在托运时声明价格并按规定支付保价费。发生损失时，按声明价格与实际损失的比例赔偿，未保价的按实际损失赔偿，但最高不超过铁道部规定的赔偿限额。
