# 禁止和限制携带物品目录

## 绝对禁止携带

下列物品禁止携带进站上车，一经发现予以收缴并移交公安机关：

- 枪支、弹药、管制刀具、警械以及各类仿制品
- 爆炸物品：炸药、雷管、导火索、烟花爆竹、发令纸等
- 易燃物品：汽油、煤油、柴油、酒精（浓度 70% 以上）、松香油、香蕉水等
- 压缩气体和液化气体：氢气、甲烷、乙炔、液化石油气、打火机充气罐等
- 自燃物品和遇湿易燃物品：黄磷、金属钠、电石等
- 氧化剂和有机过氧化物：高锰酸钾、双氧水（浓度 20% 以上）等
- 毒害品、腐蚀性物品：氰化物、砒霜、硫酸、盐酸、硝酸等
- 放射性物品及其他危害列车运行安全的物品

## 限量携带

- 气体打火机不超过 2 个，安全火柴不超过 2 小盒
- 指甲油、去光剂、染发剂不超过 20 毫升
- 冷烫精、摩丝、发胶、杀虫剂、空气清新剂等自喷压力容器不超过 120 毫升
- 酒精、香水等含易燃成分的日常用品，单体容器容积不超过 100 毫升，每种限带 1 件
- 充电宝、锂电池：标志清晰，单块额定能量不超过 100 瓦时（含）；100 至 160 瓦时的，须经车站同意并做好防护

## 检查

车站对旅客携带品进行安全检查。拒绝接受安全检查的，车站有权拒绝其进站上车。对查获的危险品，按有关规定处理。
