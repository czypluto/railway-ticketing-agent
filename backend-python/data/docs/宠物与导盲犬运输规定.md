# 宠物与导盲犬运输规定

## 一般宠物

除导盲犬外，任何活体动物一律不得带入车厢。旅客随身携带的宠物，可选择以下方式运输：

1. **办理托运**：宠物须装入符合规定的容器（笼具），笼具大小应保证动物能站立、转身。托运时须提供动物检疫合格证明。
2. **自驾或委托他人看管**：旅客自行安排。

## 容器要求

宠物笼具须具备通风、防漏、坚固、安全等条件。多个同类小动物可同笼运输。笼具底部须铺设吸水性衬垫，防止粪便渗漏污染车辆。

## 导盲犬

视力残疾旅客携带导盲犬进站乘车不受上述限制，但须满足：

- 出示残疾人证、导盲犬工作证以及动物健康免疫证明
- 导盲犬佩戴牵引链，由旅客本人牵领
- 导盲犬不得占用席位，不得进入餐车厨房区域

## 其他辅助犬

携带执行任务的军用犬、警用犬、搜救犬的，须出示所属单位证明，并按有关规定办理。

## 违规处理

违反规定携带活体动物进站上车，经劝阻拒不改正的，铁路运输企业有权拒绝其进站乘车；已乘车的，可责令其在中途站下车，并由旅客自行承担后果。
