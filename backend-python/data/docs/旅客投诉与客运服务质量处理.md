# 旅客投诉与客运服务质量处理办法

## 投诉渠道

旅客可通过以下渠道投诉：

- 12306 客服电话（24 小时）
- 12306 网站或客户端"投诉建议"
- 车站服务台、列车长现场受理
- 书面信函

## 受理时限

- 12306 客服电话与线上渠道：**24 小时内**响应
- 现场投诉：能当场答复的当场答复，不能当场答复的 **3 个工作日内**答复
- 涉及退票、赔偿等需核实的：**10 个工作日内**答复

## 投诉分类

| 类别 | 示例 | 处理主体 |
|---|---|---|
| 服务态度 | 工作人员用语不当、推诿 | 车站/客运段 |
| 服务质量 | 车内卫生、温度、广播 | 客运段 |
| 票务纠纷 | 退票收费争议、重复扣款 | 车站/票务部门 |
| 设施设备 | 电梯故障、闸机无法识读 | 车站设备部门 |

## 赔付

因铁路运输企业责任造成旅客人身伤害或随身携带品损失的，按《铁路旅客运输规程》有关条款办理赔偿。

因铁路责任造成旅客不能按票面记载的日期、车次、席别乘车的，旅客可全额退票或免费改签。

## 回访

投诉处理完毕后，应于 **7 日内**对投诉人进行回访，确认处理结果满意度，并记入服务质量管理档案。

## 统计与改进

投诉受理部门每月汇总投诉情况，分析高发问题，形成《客运服务质量分析月报》，报分管领导并督促整改。
