# 客运部内部作业标准

本文为客运部内部资料，其他部门在对话中检索不到。

## 交接班

客运部各岗位实行对口交接。交接内容包括：客流情况、设备状态、遗留问题、上级指令。交接双方须在《岗位交接记录簿》上签字。

## 作业纪律

1. 上岗前不得饮酒，不得携带与工作无关的物品。
2. 作业期间统一着装，佩戴工牌，不得擅自离岗。
3. 使用服务用语，做到"来有迎声、问有答声、走有送声"。

## 岗位巡检

值班员每 **2 小时**巡查一次责任区域，重点检查：检票闸机运行状态、引导标识完好情况、候车区秩序、消防通道畅通情况。巡检结果记入《值班日志》。

## 客运记录

发生下列情形必须填写客运记录：旅客受伤、物品损坏、列车晚点超过 30 分钟、旅客投诉、查获禁运品。

## 考核

客运部每月对岗位作业标准执行情况进行考核，考核结果与绩效挂钩。发生责任投诉的，当月考核不得评为优秀。

## 培训

新入职人员须完成不少于 **40 学时**的岗前培训并考核合格方可上岗。在岗人员每年参加不少于 16 学时的业务培训。
