# 铁路旅客运输合同与承运人责任

## 合同成立

旅客购票并支付票款后，铁路旅客运输合同成立。合同自旅客进站检票时生效，至旅客出站检票时终止。

电子客票以铁路运输企业电子信息系统中记录的车票信息为合同凭证。

## 承运人责任期间

承运人对旅客及其随身携带品承担责任的期间，自旅客检票进站时起，至旅客出站时止。

## 人身伤害赔偿

旅客在运输过程中发生人身伤害，属铁路运输企业责任的，按下列标准赔偿：

- 医疗费、护理费、误工费等按实际发生数额赔偿
- 造成残疾的，赔偿残疾赔偿金
- 造成死亡的，赔偿死亡赔偿金与丧葬费

铁路运输企业能证明伤亡是旅客自身健康原因、旅客故意或重大过失造成的，不承担赔偿责任或减轻责任。

## 随身携带品损失

因铁路运输企业责任造成旅客随身携带品损失的，赔偿限额为**每位旅客 2000 元**。已办理保价的，按声明价格赔偿。

下列物品不予赔偿：货币、有价证券、金银珠宝、古董、字画等贵重物品，以及无法证明价值的物品（旅客自行带入车内的）。

## 行李损失

托运行李发生损失，按承运人责任赔偿，赔偿限额为**每千克 20 元**；保价运输的按声明价格赔偿。

## 免责

因不可抗力、旅客自身原因或物品本身自然属性造成的损失，铁路运输企业不承担赔偿责任。

## 索赔时限

旅客索赔应在自事故发生之日起 **1 年**内提出，逾期不再受理。
