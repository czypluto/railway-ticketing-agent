# 特殊旅客服务规程

本规程适用于老、幼、病、残、孕旅客以及其他需要重点服务的旅客。

## 重点旅客预约

旅客可于乘车前 24 小时通过 12306 客服电话或网站提出重点旅客服务预约。车站接到预约后，应安排人员在约定时间、地点提供协助进站、协助乘降等服务。

未预约的，可在到站后向车站工作人员现场提出，车站视情况提供必要协助。

## 轮椅服务

持有效证件的行动不便旅客，可免费使用车站提供的轮椅。轮椅服务范围包括站台、进出站通道及候车区域。旅客自带轮椅的，应办理托运（折叠轮椅可作为免费携带品带入车厢的除外）。

## 无人陪伴儿童

年满 14 周岁以上、18 周岁以下的未成年人，可办理无人陪伴儿童运输服务。办理时须由监护人提出申请，填写交接单，并由车站指定专人负责全程照护，列车长与到站办理交接。

## 孕妇旅客

怀孕 32 周至 36 周的孕妇乘机（乘车）须提供医院出具的适宜乘车证明；超过 36 周的，不予承运。车站对临近预产期的孕妇旅客应主动提供协助。

## 导盲犬

视力残疾旅客可携带导盲犬进站乘车。携带时须出示残疾人证、导盲犬工作证及动物健康免疫证明。导盲犬应系牵引链并由旅客本人牵领，不得占用席位。
