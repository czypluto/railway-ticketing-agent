# 车站安全检查作业规范

## 总体要求

车站对进站旅客及其携带品实行安全检查。**人人必检、行李件件过机**，不得漏检。安检工作由车站客运部门组织，公安部门配合。

## 作业流程

1. **引导**：引导旅客将行李物品放置在安检仪传送带上，随身小件放入托盘。
2. **过机**：行李通过 X 光机检查，图像判读人员负责识别可疑物品。
3. **手检**：旅客通过安全门（金属探测门）后，由手检员使用手持探测器进行人身检查。安全门报警的，必须进行手检。
4. **复检**：图像判读发现可疑物品的，开包复检；复检确认属禁运品的，按《禁止和限制携带物品目录》处理。

## 人员与设备

安检员上岗前须经培训并考核合格。X 光机操作人员连续工作不得超过 2 小时，应轮换作业。

安检设备每日班前进行功能测试，发现故障立即停用并报修。

## 特殊时段

春运、暑运及重大活动期间，安检等级提升，实行**双人判图、逢包必开**。必要时可对旅客进行二次安检。

## 记录

查获禁运品的，须填写《安检查获物品登记表》，记录时间、旅客姓名、证件号、物品名称与数量，并按规定移交公安或作暂存处理。
