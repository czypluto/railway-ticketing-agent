# 综合管理部 值班与调度规程

本规程为部门内部资料，仅综合管理部可见；其他部门在对话中检索不到本文。

## 值班安排

调度值班实行 24 小时三班轮值，夜班 22:00 至次日 6:00 双人值守。交接班须填写《值班交接记录》，由交班人与接班人双方签字确认，记录保存不少于一年。

## 应急响应

接到列车晚点超过 30 分钟的报告后，值班员应在 5 分钟内向调度长报告，并同步通知客运段与车站值班室。晚点超过 2 小时的，由调度长向分管领导报告。

## 信息报送

重大运输事件须在 1 小时内形成书面简报报送分管领导，不得越级对外发布。对外口径由综合管理部统一发布。
