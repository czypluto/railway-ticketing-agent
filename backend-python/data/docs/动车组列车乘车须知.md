# 动车组列车乘车须知

## 席别

动车组列车席别分为：二等座、一等座、商务座，部分车次设特等座、优选一等座。席别对应的价格与权益以购票时公布的为准。

## 车票与座位

动车组列车实行电子客票，凭有效身份证件原件进站乘车。旅客应对号入座，不得占用他人席位，不得越席乘车。

## 大件行李

动车组列车车厢两端设有大件行李存放处，行李尺寸长宽高之和不超过 130 厘米。超过规定的须办理托运。

## 车内设施

- 二等座：座椅间距较小，小桌板设在前排座椅背后
- 一等座：座椅间距较大，设有独立扶手与脚踏
- 商务座：可平躺，配备独立娱乐屏幕

车内提供电源插座；二等座一般每排设置 2 个插座，一等座与商务座每座设 1 个。

## 餐饮

动车组列车设餐车或提供推车售货服务。也可通过 12306 客户端"餐饮特产"预订沿途车站餐饮，由车站工作人员送至座位。

## 禁烟

动车组列车**全列禁烟**，包括车厢连接处与卫生间。违反规定吸烟引发列车紧急制动的，将由公安机关依法处理。

## 静音车厢

部分动车组列车设有静音车厢。购买静音车厢车票的旅客应保持安静，使用电子设备时须佩戴耳机，接打电话请到车厢连接处。
