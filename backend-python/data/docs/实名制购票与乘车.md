# 实名制购票与乘车规定

## 购票

购买铁路客票实行实名制。购票人须提供乘车人的有效身份证件原件或复印件，一张有效身份证件同一乘车日期同一车次只能购买一张车票。

有效身份证件包括：居民身份证、临时身份证、户口簿、护照、港澳居民来往内地通行证、台湾居民来往大陆通行证、外国人永久居留身份证等。

通过互联网购票时，须在 12306 网站或客户端注册，注册时须提供真实姓名、有效身份证件号码和手机号码。一个手机号码只能注册一个账户。

## 乘车

进站乘车时，须持购票时使用的有效身份证件原件，通过实名制核验闸机完成票、证、人一致性核验。核验不通过的不予进站。

学生优惠票、残疾军人票等优惠票种，还须同时出示相应减价优待凭证。

## 代办

代他人购票的，须提供乘车人有效身份证件信息。取票时须提供乘车人证件原件或复印件。

## 违规处理

冒用他人身份证件购票乘车的，铁路运输企业有权拒绝其进站乘车，并按规定移交公安机关处理。使用伪造、变造身份证件购票的，依法追究责任。
