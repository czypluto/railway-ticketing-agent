# 车站候车与检票组织

## 候车

旅客应按车站引导进入指定候车区域候车。车站应在候车区设置饮水处、卫生间、母婴室等服务设施，并在显著位置公布列车运行信息。

重点旅客（老幼病残孕）候车区应设置在便于进出站的位置。

## 检票时间

- 普速列车：始发站一般于开车前 **30 分钟**开始检票，**开车前 5 分钟**停止检票。
- 动车组列车：始发站一般于开车前 **20 分钟**开始检票，开车前 **3 分钟**停止检票。

沿途停靠站停站时间较短，一般不开设专门检票口，由旅客自行按车厢位置候车。

## 检票方式

1. **闸机检票**：持电子客票旅客刷证或刷脸通过检票闸机。
2. **人工检票**：证件无法自动识读的旅客走人工通道，由检票员核对票、证、人一致后放行。

## 停止检票后

停止检票后到达的旅客，车站不再放行。旅客可按规定办理改签或退票。

## 站台安全

旅客进入站台后应在安全线以内行走，不得跨越安全线。站台作业人员应引导旅客有序乘降，做到"先下后上"。

## 客流高峰组织

春运、暑运及小长假期间，车站应制定客流组织方案，实行分时段、分区域候车与检票，必要时启用备用候车区并加开检票通道。
