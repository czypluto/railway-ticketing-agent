# 铁路客运运价规则（摘要）

## 票价构成

旅客票价由**基本票价**和**附加票价**两部分构成：

- 基本票价：按运价里程与列车等级计算
- 附加票价：包括空调费、卧铺费等

票价按席别分为硬座、软座、硬卧、软卧、二等座、一等座、商务座等，动车组列车票价实行浮动机制。

## 票价计算

普速旅客列车硬座基本票价：运价里程 200 公里以内的，按每人公里 0.05861 元计算；超过 200 公里的部分递减。

动车组列车票价由铁路运输企业根据市场需求自主确定，实行公布票价与执行票价制度，执行票价不得高于公布票价。

## 儿童票价格

儿童优惠票按相应席别公布票价的 **50%** 核收。免费乘车儿童超过规定人数时，超出部分购买儿童优惠票。

## 学生票价格

学生优惠票：动车组列车**二等座**按公布票价的 **75%** 核收；普速列车**硬座**按公布票价的 **50%** 核收。其他席别不享受学生优惠。

## 计价单位

票价以**元**为单位，不足 1 元的按四舍五入处理。退票费以**角**为单位，不足 1 角的按四舍五入处理。

## 变更手续费

改签票价高于原票价的，补收差额；低于原票价的，退还差额。差额按上述票价规则计算。
