# 电子客票使用说明

## 什么是电子客票

电子客票是以电子数据形式体现的铁路旅客运输合同。旅客购票后不再需要换取纸质车票，凭购票时使用的有效身份证件原件即可进站、乘车。

## 进站乘车

1. 通过 12306 网站、客户端或车站售票窗口、自动售票机购票。
2. 持购票时使用的有效身份证件原件，在实名制核验闸机刷证进站。
3. 检票口刷证（或刷脸）检票乘车。
4. 到站后刷证出站。

## 报销凭证

需要报销凭证的旅客，可在**开车前或乘车日期之日起 180 日内**，凭购票时使用的有效身份证件原件，到车站售票窗口、自动售（取）票机换取报销凭证。

报销凭证只能开具一次，换取后不能重复开具。已换取报销凭证的车票办理退票时，须交回报销凭证。

## 特殊情形

- 身份证件无法自动识读的，可走人工核验通道。
- 使用同行人证件购票的，须持实际乘车人身份证件进站。
- 儿童未办理身份证件的，可使用同行成年人身份证件信息购票，人工核验时出示儿童有效证件。

## 变更与退票

电子客票的改签、退票可通过 12306 网站、客户端或车站窗口办理。已换取报销凭证的，须到车站窗口办理并交回报销凭证。
