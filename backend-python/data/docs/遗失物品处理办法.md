# 旅客遗失物品处理办法

## 车上遗失

在列车上遗失物品的，可向列车工作人员或列车长报告，也可在到站后向车站服务台登记。列车工作人员拾获遗失物品后，应填写《拾获物品登记表》，列车到达终点站后移交车站。

## 车站遗失

在车站遗失物品的，向车站服务台（失物招领处）登记，提供物品特征、遗失时间与地点。

## 保管期限

- 一般物品：自接收之日起保管 **90 天**
- 食品、鲜活易腐物品：保管 **24 小时**，逾期按规定处理
- 贵重物品（现金、首饰、有价证券等）：保管 90 天，须专柜保管并双人登记

超过保管期限无人认领的，按有关规定处理；其中贵重物品移交公安机关。

## 认领

认领遗失物品须出示本人有效身份证件，并说明物品特征。委托他人认领的，须提供委托书、委托人及受托人身份证件。

## 查询渠道

可通过 12306 客服电话、车站服务台或 12306 客户端"遗失物品查找"功能查询。铁路运输企业可为旅客提供物品寄送服务，寄送费用由旅客承担。
