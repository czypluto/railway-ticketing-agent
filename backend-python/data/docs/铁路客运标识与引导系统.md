# 铁路客运标识与引导系统设置规范

## 标识分类

车站客运标识分为：导向标识、位置标识、信息标识、安全警示标识、服务设施标识五类。

## 导向标识

导向标识应连续设置，自进站口起至站台、出站口，形成完整引导链。关键节点包括：售票厅、进站口、安检区、候车区、检票口、站台、出站通道。

- 颜色：导向标识底色为**深蓝色**，文字与图形为白色
- 高度：悬挂式导向标识下沿距地面不低于 2.2 米
- 间距：主要通道内导向标识间距不超过 **30 米**

## 信息标识

信息标识包括列车时刻表、车次显示屏、晚点公告、票价表等。动态信息应保证**至少每 5 分钟**刷新一次。

## 安全警示标识

安全警示标识采用**黄底黑字**（警告）或**红底白字**（禁止），设置于站台边缘、电扶梯、楼梯口、设备用房等处。

站台安全线标识宽度不小于 100 毫米，距站台边缘不小于 800 毫米。

## 服务设施标识

卫生间、母婴室、饮水处、重点旅客候车区、服务台等设施应在显著位置设置标识，并配有图形符号。标识应符合国家标准 GB/T 10001 的规定。

## 无障碍要求

标识系统应满足无障碍要求：关键导向标识配盲文或触觉标识；字幕显示屏应同时提供语音播报；轮椅通道标识清晰连续。

## 维护

标识破损、褪色、信息过期的，应于发现后 **24 小时内**修复或更换。
